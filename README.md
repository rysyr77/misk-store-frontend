# متجر مسك للعطور — واجهة أمامية

واجهة متجر عربية متجاوبة من اليمين إلى اليسار، بهوية سوداء وذهبية، مستوحاة من الصورة المرجعية. لا يتطلب المشروع Git أو خادماً أو قاعدة بيانات أو تثبيت حزم.

## التشغيل

افتح `index.html` في المتصفح، أو شغّل خادماً محلياً بسيطاً من مجلد المشروع:

```bash
python3 -m http.server 8080
```

ثم افتح `http://localhost:8080`.

## دخول المدير التجريبي

انقر مرتين على الشعار في الترويسة، ثم أدخل: اسم المستخدم `admin` وكلمة المرور `misk123`. هذه حماية شكلية للواجهة فقط، وليست مصادقة آمنة؛ بيانات التحقق موجودة في JavaScript ويمكن تجاوزها. لا تستخدم هذه النسخة لحماية بيانات حساسة. المصادقة الحقيقية تتطلب خادماً. إضافة المنتجات وتعديلها وحذفها تحفظ محلياً في `localStorage` على المتصفح الحالي، ولا تُرسل البيانات إلى خادم أو تظهر على أجهزة أخرى. يمكن استعادة بيانات العرض الأصلية بمسح بيانات الموقع (Local Storage) للصفحة.

## أهم الملفات

- `index.html` — بنية أقسام المتجر، نافذة التفاصيل، الدخول ولوحة الإدارة.
- `styles.css` — الهوية البصرية والتنسيق المتجاوب.
- `app.js` — المنتجات التمثيلية، تصفية المنتجات، نافذة التفاصيل، طلبات واتساب المباشرة ولوحة الإدارة.
- `assets/` — صور المتجر، صورة العبوة بالشعار في `misk-hero-branded.png`، والشعار الشفاف `misk-logo.png`.

رابط واتساب في الواجهة يستخدم الرقم الظاهر في المستند والصورة المرجعية: `+963 306 993 027 531`. يمكنك تعديل `WHATSAPP_NUMBER` أعلى `app.js` إذا أردت تغيير الرقم.

## ملاحظات النطاق

هذه نسخة Frontend فقط؛ تسجيل الدخول تجريبي وغير آمن ولا توجد مصادقة حقيقية. زر طلب المنتج يفتح واتساب برسالة تتضمن تفاصيل المنتج والكمية والإجمالي. لا توجد خدمة طلبات أو مدفوعات أو إدارة بيانات على الخادم. الخط العربي يُحمّل من Google Fonts عند توفر الإنترنت، مع خطوط احتياطية عند عدم توفره.
